# kleash/homebrew-tap

Homebrew casks for:

- [AirSCP](https://github.com/kleash/airscp), a native Mac app for SFTP/SCP file transfer, SSH and Windows Remote
  Desktop.
- [Crate](https://github.com/kleash/crate), a free, open-source archive utility: browse, Quick Look, extract and
  create ZIP, 7-Zip, RAR, TAR and more.
- [Activiti Modeler](https://github.com/kleash/activiti-modeler), a BPMN and DMN modeler for Activiti, with an embedded
  engine to deploy, run and test the models.

```sh
brew install kleash/tap/airscp
brew install kleash/tap/crate
brew install kleash/tap/activiti-modeler
```
